# Simple HTML Form Project

This project is a simple HTML form that collects a user's name and WhatsApp number. It is styled with a black background and burgundy color, providing a visually appealing interface.

## Project Structure

```
simple-html-form
├── src
│   ├── index.html        # HTML structure of the form
│   ├── styles
│   │   └── main.css      # Styles for the project
│   └── scripts
│       └── norion.js     # JavaScript for Norion connection and form handling
└── README.md             # Project documentation
```

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd simple-html-form
   ```

3. **Open the `src/index.html` file in a web browser** to view the form.

## Usage

- Fill in your name and WhatsApp number in the provided fields.
- Submit the form to connect with Norion.
